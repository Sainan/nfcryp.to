Case Study: 2-Factor Authentication

You already know it: scan a QR code to get endless 6-digit login codes. The idea behind this is that while a password is something you know, your phone is something you have, hence a second authentication factor. But an NFC tag is also something one can have. So, let's use it for 2-factor authentication...

  2. Read the NFC tag to get a 6-digit login code: NFC Authenticator
